Installer Atelier Photo

Pour un Mac avec une puce Apple M1, M2, M3… et macOS 15 ou supérieur. Vérifiez dans le menu Apple → À propos de ce Mac.

Tout est inclus dans l'application. Vous n'avez à installer ni Python, ni Homebrew, ni Xcode. Aucun Terminal, compte développeur Apple ou certificat n'est nécessaire. Le programme et son modèle d'analyse fonctionnent localement.

  1. Dans la fenêtre du DMG, glissez AtelierPhoto.app sur le raccourci Applications. Attendez la fin de la copie. Si une version est déjà ouverte, fermez-la avant de la remplacer.
  2. Éjectez le disque « Atelier Photo » depuis Finder.
  3. Ouvrez le dossier Applications, puis double-cliquez sur AtelierPhoto.

Si macOS bloque le premier lancement

Cette version de test n'a pas de certificat Developer ID et n'est pas notarisée par Apple. Le premier lancement peut demander votre autorisation.

  1. Après avoir tenté d'ouvrir AtelierPhoto, ouvrez Réglages Système → Confidentialité et sécurité.
  2. Repérez le message concernant AtelierPhoto, puis cliquez sur Ouvrir quand même.
  3. Confirmez avec le mot de passe du Mac ou Touch ID si demandé, puis cliquez sur Ouvrir.

Les fois suivantes, un double-clic suffit. Ne désactivez pas les protections du Mac. Si l'app est déclarée endommagée ou si l'autorisation n'est pas proposée, conservez le message pour le transmettre à la personne qui vous a fourni l'application. Un Mac géré par une entreprise peut avoir des restrictions supplémentaires.

Commencer le test

Créez un profil, ajoutez les photos de référence, puis importez un nouveau lot. Vérifiez la sélection et les retouches, validez et exportez. Les originaux restent intacts. L'archive du programme ne contient aucun profil ni photo personnelle de Windows.

Les profils sont conservés dans votre bibliothèque utilisateur, séparément du programme. Vous pouvez remplacer l'application sans effacer cette mémoire. Pour désinstaller le programme, placez AtelierPhoto.app dans la corbeille ; la mémoire reste conservée.
